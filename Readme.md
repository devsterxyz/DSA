# DSA / LeetCode Practice Repository

This repo is my personal collection of Data Structures and Algorithms questions I have solved topic-wise. It contains solutions to problems from LeetCode and other DSA practice sources, organized by topic for easier revision and tracking.

## Purpose

- Practice problem-solving regularly
- Strengthen core DSA concepts
- Track progress topic by topic
- Prepare for coding interviews and contests

## Repository Structure

- `Array/` – array problems, subarrays, matrix problems, and common array patterns
- `Strings/` – string manipulation, palindrome, anagrams, and related problems
- `LinkedList/` – linked list operations, cycle detection, reversing, merging, and list-based problems
- `Stack/` – stack problems and stack/queue implementations
- `Tree/` – binary tree and BST problems
- `Heap/` – heap-based and priority queue problems
- `Backtracking/` – combinations, permutations, subsets, N-Queens, and recursion-based search
- `Binary searches/` – binary search variants and sorted-array search problems
- `Sliding_Window/` – sliding window optimization questions
- `Sorting techniques/` – bubble sort, insertion sort, merge sort, quick sort, and selection sort
- `Tries/` – trie data structure and prefix-based problems
- `1-d_programing/` – 1D dynamic programming problems

## How to Use

1. Open the folder matching the topic you want to revise.
2. Pick the problem file.
3. Read the solution and understand the approach.
4. Compile and run the code locally if needed.

Example:

```bash
g++ Array/two_sum.cpp -o two_sum
./two_sum
```
